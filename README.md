# TaskHub - Sun* Internship Project

TaskHub is a Task Management API application developed as part of the Sun* Internship Program.

## Tech Stack
- **Language**: Python 3.10+
- **Framework**: FastAPI
- **Data Validation & Settings**: Pydantic v2 & Pydantic-Settings
- **ORM & Database**: SQLAlchemy 2.0 & SQLite
- **Server**: Uvicorn
